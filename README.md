# Чёрная дыра (Black Hole) — мод для Minecraft 1.21.1 (Fabric)

Предмет **«Чёрная дыра»**: бросаешь раз в 10 секунд, на месте падения появляется чёрная дыра.

* поглощает **блоки в радиусе 15** (съедает изнутри наружу, радиус растёт, блоки спиралью улетают в центр);
* затягивает **мобов в радиусе 25**; у горизонта событий они получают смертельный урон и погибают
  (обходит броню, тотем бессмертия, эффекты и зачарования; игроки в творческом/наблюдателе игнорируются);
* внешний вид: чёрная сфера-тень, аккреционный диск с доплеровской яркостью и вращающимися рукавами,
  линзированное гало над/под тенью, свечение, ударная волна при схлопывании, свои звуки;
* иконка — анимированная, получена настоящей трассировкой лучей в метрике Шварцшильда (`tools/gen_textures.py`).

**Крафт:** звезда Незера в центре + 4 стекла сверху/снизу/слева/справа.

```
  .  G  .
  G  N  G      G = стекло, N = звезда Незера
  .  G  .
```

## Сборка через GitHub (самый простой способ)

1. Создай репозиторий на GitHub и залей в него **всё содержимое этой папки** (важно: папка `.github` тоже):
   ```bash
   git init
   git add .
   git commit -m "Black Hole mod"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/<репозиторий>.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** → workflow **Build mod** запустится сам (или нажми *Run workflow*).
3. Через 3–6 минут открой завершённый запуск → внизу **Artifacts** → скачай `blackhole-mod`.
   Внутри архива лежит `blackhole-1.0.0.jar` — это и есть мод.

`gradle-wrapper.jar` в репозитории не нужен: workflow сам ставит Gradle 8.10.2 и JDK 21.

## Установка

Нужны: Minecraft **1.21.1**, **Fabric Loader ≥ 0.16**, **Fabric API** (для 1.21.1).
Положи `blackhole-1.0.0.jar` и Fabric API в папку `mods`.

## Сборка локально

JDK 21 + Gradle 8.10+:
```bash
gradle build            # jar появится в build/libs/blackhole-1.0.0.jar
gradle runClient        # запуск клиента для теста
```
(Если хочешь `./gradlew`: один раз выполни `gradle wrapper --gradle-version 8.10.2`.)

## Настройки

Всё в одном файле: `src/main/java/com/blackhole/BlackHoleConfig.java` — перезарядка, время жизни, радиусы,
лимиты нагрузки на тик, тратится ли предмет при броске, неуязвим ли бросивший, поедать ли выпавшие предметы.

## Структура

| Путь | Что там |
|---|---|
| `src/main/java/.../entity/BlackHoleEntity.java` | логика дыры: поедание блоков, притяжение и убийство мобов |
| `src/main/java/.../entity/SuckedBlockEntity.java` | визуальный блок, летящий в дыру (траектория считается аналитически, почти без трафика) |
| `src/client/java/.../render/BlackHoleEntityRenderer.java` | отрисовка дыры (геометрия + аддитивное свечение) |
| `src/client/java/.../render/BlackHoleShading.java` | физика цвета: доплер, красное смещение, температура диска |
| `tools/` | генераторы текстур/звуков (numpy, scipy, pillow, ffmpeg) и превью шейдинга |
